# yanak-feedback

このリポジトリは、**yanak.dev 各種プロジェクト**に関する  
**不具合報告・改善提案・質問** を受け付けるための公開フィードバック窓口です。

---

## 🐞 バグ報告（Bug Report）

バグ報告の場合は、以下の情報を含めていただけると助かります：

- 使用端末（例：Pixel 9）
- OS / バージョン
- アプリ名 / バージョン（例：AppName v1.0）
- 発生した現象
- 再現手順
- スクリーンショット（可能であれば）

👉 **[Bug Report を作成する](../../issues/new?template=bug_report.yml&labels=bug)**

---

## ✨ 改善提案（Feature Request）

「あったらいいな」「使いにくい部分がある」などの改善提案はこちら：

👉 **[Feature Request を作成する](../../issues/new?template=feature_request.yml&labels=enhancement)**

---

## 📚 質問 / その他

使用方法・仕様に関する質問はこちら：

👉 **[Question を作成する](../../issues/new?template=question.yml&labels=question)**

---

## 🔒 ソースコードについて

本リポジトリは **Issue専用** です。  
実際の開発は **プライベートリポジトリ** で行っています。

報告いただいた内容はすべて確認し、  
対応状況はここで公開します。

---

## 🙏 ありがとうございます

いただいたフィードバックは、  
yanak.dev のサービス改善に役立てていきます。
